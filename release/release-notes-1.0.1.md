# 更新日志 v1.0.1

- 首次发布：2026-09-04
- 最近更新：2026-09-15

本版本在基础桌宠能力之上，补齐了完整的角色管理、主题设置、AI 对话与语音、外部消息接入以及自动化验收链路，并集中修复了透明窗口、拖动、模型加载、聊天布局和会话持久化等问题。

## 桌宠与互动

- 完善单击、双击、三击和长按反馈：可根据头部或身体命中区域触发不同动作、表情、粒子和窗口反馈。
- 新增鼠标滚轮缩放，按 5% 步进调整当前角色尺寸；每个模型独立保存比例，并在达到 50% / 200% 边界时继续给出状态提示。
- 完善拖动体验，支持多显示器、分数 DPI、屏幕边缘和跨屏位置恢复；常用位置可一键移动到当前显示器四角或中央。
- 新增精细角色命中、完整透明窗口“背景检测”和全局鼠标穿透锁定三种交互范围。
- Live2D 角色支持近距离光标跟随，驱动头部、眼睛和身体参数；光标远离后平滑回正并减少无效采样。
- 新增闲置行为：30 秒进入普通待机、90 秒提示困倦、180 秒进入深度休息，有效互动会重新计时。
- 新增自适应渲染调度，按活动状态在 60 / 30 / 20 / 10 FPS 间切换，也可固定选择省资源或高质量模式。
- 新增“安静陪伴 / 自然互动 / 省电陪伴”三组快捷预设，同时保留逐项微调能力。
- 系统托盘和角色右键菜单补齐互动、聊天、暂停动画、切换角色、锁定、刷新模型、设置和退出等入口。
- 优化模型切换、隐藏与恢复时的资源管理，正确清理或恢复 WebGL、透明视频、纹理、音频和动画调度状态。

## 角色与模型管理

- 新增透明 WebM 动画角色 `deepseek-pet`，包含待机、工作、拖动、开心、害羞、困倦、挥手、吃零食等多种语义动作。
- 当前内置角色包括 `mori-suit`、`hiyori`、`mao_pro`、`cafe-gun` 和 `deepseek-pet`；全新用户默认使用 `mori-suit`。
- 设置页角色列表升级为卡片视图，可自动生成并缓存封面，支持横向浏览、拖动排序、切换、昵称和独立尺寸。
- 新增角色档案编辑，可分别设置基础设定、世界观、与用户的关系和表达规则，并将其用于对应角色的 AI 提示词。
- 新增动作与表情预览，可在设置页直接检查当前模型提供的资源和语义映射。
- 新增从设置页直接导入 `.zip` 模型包；导入前会校验格式，无效文件不会写入用户目录，重名时自动追加序号而不覆盖原模型。
- 保留用户模型目录 `%APPDATA%\Live2DCompanion\models`，其中的同名模型优先于安装包内置版本，应用升级或卸载不会删除用户模型。
- 完善 Cubism 3/4 目录模型与 ZIP 模型兼容性，修复 Windows `file://` 路径下 moc、纹理、physics、动作和表情资源解析失败的问题。

## 设置页与视觉体验

- 设置窗口整理为“角色 / 行为 / AI / 系统”四个页面，设置即时生效并自动保存。
- 新增“玻璃拟态 / 治愈手账”两套完整主题，每套主题可独立选择玻璃、甜美、像素或科幻对话气泡。
- 新增可复用的对话气泡组件，补齐普通消息、长消息、思考中、语音合成中和正文展示状态。
- 支持将桌面宠物实时画面作为设置页动态背景，并尊重系统的减少动态效果偏好。
- 优化设置页布局、滚动条、搜索选择器、模型卡片、插件卡片和长路径展示，避免说明文字被固定高度裁切。
- 全新用户首次启动时自动打开居中的设置窗口；已有配置升级不会重复弹出。
- 普通打开设置时保留用户当前页签，只有明确入口才跳转到指定页面。

## AI 对话与语音

- 内置 DeepSeek 文本对话适配器，支持 `deepseek-v4-flash` 与 `deepseek-v4-pro`。
- 内置智谱 `glm-tts` 语音适配器，可选择音色并调整语速和音量。
- 新增阿里云百炼 `qwen3-tts-flash` 非实时语音适配器，提供 48 个官方音色及在线试听。
- 文本模型与语音模型可独立配置、启用或停用；只启用文本模型时也可以正常聊天。
- 对话记录按角色隔离并持久化，切换角色后恢复各自历史；支持配置历史条数和回复长度，并可只清空当前角色的对话。
- 角色昵称、档案和表达规则会进入系统提示词；模型返回的情绪标签可转换为角色动作与表情。
- AI 回复可同步显示在底部聊天面板和跟随角色位置的气泡中；语音播放时实时驱动 Live2D 口型。
- 聊天面板支持折叠、静音、单条语音重播、清空记录和稳定的长消息滚动阅读。
- DeepSeek、智谱和阿里云百炼 API Key 优先读取项目根 `.env`，缺项时回退同名系统环境变量；旧版本通过系统安全存储加密保存的 Key 仅作为兼容兜底。完整 Key 不回显、不写入普通配置或日志。
- 生成的 TTS 音频按月份归档到用户数据目录，应用升级不会覆盖。

## 外部系统接入

- 新增可选的本机外部消息服务，可通过统一 HTTP POST 接口或 WebSocket 向桌宠发送消息。
- 支持“直连消息”和“AI 问答”两种模式，并可为单次请求独立指定是否启用语音播报。
- 新增请求 ID 幂等、输入校验、串行队列、实时状态事件和消息历史，减少重复请求与并发覆盖。
- App 内消息与外部消息使用 `APP` / `外部` 来源标识；外部消息以最高优先级占用角色气泡，但不会打开、写入或改变底部聊天框。
- App 对话和外部 AI 问答使用独立上下文与请求通道，不会相互取消、串话或混用历史。
- 外部语音按“消息文本 + 当前 TTS 插件声明的语音配置”持久缓存；不同模型、音色、语速或音量不会错误共用缓存。
- 新增独立的外部消息测试台，包含消息调试、实时事件、消息历史和 API 文档页面，可从系统托盘进入。
- AI 和语音阶段气泡会保持到真实任务结束：`思考中…` 在 AI 完成后切换，`语音合成中…` 在 TTS 完成后切换为正文；过程文字不写入会话历史。

## 修复

- 修复应用失焦时透明窗口顶部出现白色横条的问题：升级 Electron 37.10.3，并保留失焦强制重绘兜底。
- 修复 Electron 37 `forward` 鼠标钩子泄漏导致穿透状态无法清除、角色完全不能交互的问题。
- 修复隐藏宠物后再次显示无法拖动的问题；隐藏改为移出屏幕，避免破坏渲染进程输入状态。
- 修复引导期尚未点击“开始使用”时宠物提前出现，以及可通过托盘绕过引导的问题。
- 修复多显示器环境下“移回屏幕右下角”错误定位到主屏，而不是当前屏幕的问题。
- 修复拖动透明原生窗口时设置页动态角色偶发消失的问题；透明帧不再覆盖最后一张有效画面，松开后可自动恢复。
- 修复模型切换或加载失败期间设置页动态背景闪空的问题，旧模型有效画面会保留到新模型首帧就绪。
- 修复聊天面板展开后底部操作区超出 400 × 600 宠物窗口的问题。
- 修复打开聊天错误显示整窗边框的问题；整窗轮廓现在只由“背景检测”状态控制。
- 修复 AI 插件说明被截断或为塞入固定卡片而过度缩小字号的问题。
- 修复快速切换角色时，较早的异步会话恢复结果覆盖当前角色聊天记录的问题。
- 修复角色尺寸反馈在聊天打开时遮挡内容，以及透明窗口穿透导致后续滚轮事件丢失的问题。

## 安装、更新与开发质量

- 产品名统一为 `Live2DCompanion`，安装包和数据目录同步调整；旧中文版数据会自动迁移。
- 安装方式改为按用户安装，无需管理员权限，默认安装到 `%LOCALAPPDATA%\Programs`。
- 设置页会自动检查远程 `latest.yml`，发现更高版本后显示下载入口，也支持手动检查更新。
- 新增设置页、聊天、动态背景、目录模型、Video Pet、角色会话、模型反应、Qwen-TTS、TTS 缓存、托盘和外部消息服务等定向 QA。
- 正式应用包会排除 `设计稿/`、`design-demos/`、`docs/`、`plan/`、`release/`、`qa/` 及其他开发期文件，避免把原型、设计图、测试脚本和内部文档带入安装包。
- 发版脚本支持从 `.env` 或系统环境变量读取七牛云配置，构建后自动覆盖上传 EXE、`latest.yml` 和当前版本说明，并刷新对应 CDN 文件缓存。
- README 新增可直接访问的 Windows EXE 体验地址、带日期与简要说明的历史版本表，以及角色、行为、AI、系统四页预览图。
- 新增 App 设计稿和 AI 设计优先开发规范：UI 开发必须先按选定设计图锁定主题与风格，再编码和截图验收。
- 仓库新增宠物模型开发与 AI 模型开发规范，记录模型格式、插件清单、凭据、语音、情绪、持久化和验证约定，便于后续扩展保持兼容。
