# 更新日志 v1.0.1（2026-09-04）

## 修复

- 修复应用失焦时透明窗口顶部出现白色横条的问题（升级 Electron 37.10.3，含上游回归修复；失焦时强制重绘兜底）
- 修复鼠标交互完全失效的问题：Electron 37 的 `forward` 鼠标钩子泄漏导致穿透状态无法清除，已移除该机制
- 修复隐藏宠物后再次显示无法拖动的问题：隐藏/显示循环会破坏渲染进程的输入接收，隐藏改为将窗口移出屏幕
- 修复角色边缘（头顶、裙摆、尾巴）抓取不到的问题：模型加载后整个窗口均可交互拖动
- 修复引导期（未点击「开始使用」）宠物提前出现、托盘可绕过引导的问题
- 修复「移回屏幕右下角」在多显示器下定位到主屏而非当前屏的问题

## 新增

- 设置页角色列表改为卡片视图，并自动生成每个角色的封面缩略图（缓存于应用数据目录）
- 用户自定义模型：把模型文件夹或 `.zip` 放入应用数据目录的 `models` 文件夹（`%APPDATA%\Live2DCompanion\models`），托盘「刷新模型列表」后即可使用；卸载或更新程序不会删除
- 设置页「打开模型文件夹」快捷入口
- 窗口位置预设：左上角 / 右上角 / 左下角 / 右下角 / 居中（以当前显示器为基准）
- 版本检查更新：打开设置自动检查 `latest.yml`，发现新版本显示「下载更新」按钮，也可手动「检查更新」

## 变更

- 产品名改为英文 `Live2DCompanion`，安装包与数据目录相应调整；旧中文版数据自动迁移
- 安装方式改为按用户安装（免管理员权限），默认安装到 `%LOCALAPPDATA%\Programs`
- 精简正式应用包：仓库中的 `design-demos/` 设计原型、验证脚本和视觉素材不再随安装包发布
