API 接入说明仅监听本机 127.0.0.1 · HTTP 业务接口统一使用 POST

协议与地址

消息 POST/api/v1/messages
服务状态/api/v1/health
能力发现/api/v1/session
消息历史/api/v1/history
清空历史/api/v1/history/clear
语音试听/api/v1/history/audio/{messageId}
WebSocket/api/v1/events

消息参数

字段类型 / 默认值说明
typedirect | relay，必填direct 原样展示，不调用 AI；relay 发起 AI问答并返回 AI 回复。
contentstring，必填消息正文，去除首尾空白后 1–2,000 个字符。
speakboolean，false是否对最终展示文本执行语音合成与播报。
senderstring，“外部系统”外部来源名称，最多 60 个字符。
requestIdstring，自动生成幂等键，10 分钟内重复 ID 返回同一处理结果，最多 120 个字符。
useCurrentCharacterProfileboolean，truerelay 是否使用当前角色昵称与人设；false 时使用中性问答助手。
useExternalContextboolean，truerelay 是否读取并写入独立的外部上下文；false 时本次请求无历史、也不留 AI 上下文。

POST /api/v1/messagesContent-Type: application/json

{  "type": "relay",  "content": "提醒用户十分钟后参加项目例会",  "speak": true,  "sender": "日程系统",  "requestId": "calendar-20260914-001",  "useCurrentCharacterProfile": true,  "useExternalContext": true}

WebSocket 发送与事件

连接 /api/v1/events 后以 message.post 发送。服务返回 ready / result / error，并广播 received / progress / completed / failed；progress 仅为不入历史的临时状态。

历史与语音试听

消息历史保留完整请求、完整响应与最终对话，不保存“思考中”或“语音合成中”。语音合成后先归档到本地，再由历史中的 audioUrl 读取并试听；speech.cached 表示是否命中外部语音缓存。Qwen-TTS 按文本、模型和音色缓存，GLM-TTS 还包含语速与音量。除历史语音试听外，HTTP 业务接口统一使用 POST。

隔离说明：外部消息优先占用角色上方气泡，但绝不打开、关闭、折叠、锁定或写入 App 底部聊天框；App 历史只保存 App 消息。AI问答使用独立上下文与独立请求通道，不会取消正在进行的 App 对话。
