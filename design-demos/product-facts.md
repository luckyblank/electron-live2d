## 已确认

- 产品名：`Live2DCompanion` / Live2D 桌面伙伴。
- 当前本地版本：`1.0.1`。
- 目标平台：Windows 10/11 x64。
- 技术形态：Electron 桌面应用，源码由原生 JavaScript、HTML、CSS 直接加载。
- 桌面角色窗口：透明、无边框、默认始终置顶，支持 Live2D 与透明 WebM 角色。
- 设置窗口：固定为 470 × 760 px，分为「角色 / 行为 / AI / 系统」四页。
- 默认内置角色：`mori-suit`；仓库还包含 `hiyori`、`mao_pro`、`cafe-gun` 与 `deepseek-pet`。
- 桌面互动：单击、双击、三击、长按、拖动、滚轮缩放、光标跟随、闲置与休息状态。
- 陪伴预设：安静陪伴、自然互动、省电陪伴。
- AI：文本模型与语音模型独立配置；支持逐角色档案、逐角色历史、情绪到动作/表情映射。
- 当前内置 AI 示例：DeepSeek 文本对话、智谱 GLM-TTS、阿里云百炼 Qwen3-TTS Flash。
- 设置主题：玻璃拟态、治愈手账。
- 气泡样式：玻璃、甜美、像素、科幻。
- 系统功能：始终置顶、登录时启动、动态角色背景、减少动态效果、应用内更新、外部消息服务、APP 长截图。
- API Key 可以读取环境变量，也可经 Electron `safeStorage` 加密保存在本机；完整 Key 不回显。

## 原型边界

- 原型只做本地状态模拟，不调用 Electron IPC、AI、TTS、更新或外部消息接口。
- 原型不会读取环境变量、用户配置或真实 API Key。
- `deepseek-pet` 的透明 WebM 是当前仓库中可直接复用的真实角色影像。
- 其他 Live2D ZIP 模型的封面由正式应用运行时生成；独立 HTML 无法可靠读取用户数据目录中的封面，因此原型对缺失封面使用明确的运行时占位，不手绘角色代替。
